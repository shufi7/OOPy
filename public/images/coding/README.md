# Ilustrasi latihan Coding

Salin SVG yang disediakan pemilik proyek dengan pemetaan berikut:

| File sumber | Nama di direktori ini |
| --- | --- |
| `OOPy_Latihan1_SensorAir_Sesuai_Soal.svg` | `latihan-1-sensorair.svg` |
| `OOPy_Latihan2_Ekosistem_Rawa_Multifile_Sesuai_Soal.svg` | `latihan-2-ekosistem-rawa.svg` |

Halaman `/coding` otomatis menampilkan setiap ilustrasi setelah file tersedia.
Sebelum itu, elemen gambar tidak dirender agar tidak muncul gambar rusak atau
ruang ilustrasi kosong. Jangan mengganti SVG dengan ilustrasi generik.

Ulangi `node tests/browser/coding-index.mjs` setelah menyalin kedua file untuk
memeriksa pemuatan, teks alternatif, dan `object-fit: contain`.

# Implementasi Tahap 2: beranda OOPy

Tanggal: 16 Oktober 2026, WITA. Mode Anti-Slop: **after**, melanjutkan audit dan Tahap 1 yang telah disetujui. **Tahap 2 selesai; Delivery Gate PASS untuk cakupan beranda yang diperiksa.** Tahap 3 belum dimulai.

## Acuan dan batas pekerjaan

Menggunakan [DESIGN.md](../DESIGN.md), [audit awal](audit-001-2026-10-16.md), dan [laporan Tahap 1](stage-1-2026-10-16.md), bersama skill `antislop`, `antislop-ui`, `antislop-copywriting`, `antislop-human`, dan `antislop-layoutmobile` lokal. Dokumen desain menjadi pedoman visual; batas implementasi mengikuti permintaan pengguna.

Design Read: beranda ruang belajar OOP Python bagi mahasiswa/pengguna baru, tenang dan ramah dengan identitas mint-teal, judul manfaat praktik sebagai fokus, serta logo bekantan sebagai identitas pendukung. **ENERGY 2 / RHYTHM 2 / MOTION 1.**

Baseline git: `1c08e17085aa03e4d4be235d0dcb99254ae6af2e`. Working tree bersih saat tahap ini dimulai. Perubahan aplikasi hanya dua file beranda. Backend, route, database proyek, autentikasi, materi, grading, Monaco, Pyodide, komponen bersama, dan fondasi Tahap 1 tidak diubah.

### Kontras terhitung

Rumus luminansi relatif sRGB WCAG diterapkan pada `getComputedStyle()` dengan latar solid ancestor yang sebenarnya. Ambang 4,5:1 untuk teks normal, 3:1 untuk teks besar dan indikator nonteks. Berikut sampel dari 34 pengukuran beranda, bukan perkiraan screenshot:

| --- | --- |
| Heading gelap pada canvas | 11,41:1 |
| Aksen judul action teal pada canvas | 5,85:1 |
| Deskripsi pada canvas | 8,02:1 |
| Primary normal / hover / active / focus | 6,11 / 7,43 / 9,47 / 7,43:1 |
| Secondary normal / hover / active / focus | 5,34 / 6,79 / 8,64 / 6,79:1 |

Semua pasangan teks yang diperiksa memenuhi ambang. Fokus kedua CTA memiliki outline 3px dan rasio terhadap canvas lebih dari 3:1. Kontrol bersama dan state disabled tetap dilindungi pemeriksaan regresi fondasi; beranda tidak menambahkan kontrol disabled baru.

## Batas verifikasi dan pekerjaan tersisa

- Belum diuji pada perangkat fisik, Safari/Firefox, screen reader, forced colors, atau zoom browser 200%. Uji viewport adalah pemeriksaan reflow/geometri browser, bukan pengganti seluruh pemeriksaan tersebut.
- Tidak menjalankan ulang seluruh suite browser `coding.mjs` dan `live-code.mjs` pada tahap ini. Suite PHP/JS dan foundation browser dijalankan ulang; source kedua fitur tidak berubah.
- Grader produksi eksternal tidak diuji end-to-end; endpoint grader server sementara sengaja tidak tersedia. Tidak ada klaim perubahan atau verifikasi produksi grading.
- Tidak menjalankan build Vite karena Blade memuat `public/css/oopy/home.css` langsung dan pipeline aset tidak berubah; hasil CSS/Blade sudah dijalankan dalam browser.
- Temuan halaman dashboard, materi, coding, dan autentikasi di luar cakupan beranda tetap mengikuti audit awal/tahap berikutnya. Tidak ada masalah beranda tersisa yang ditemukan pada kondisi yang diuji.
- Tahap 3 menunggu instruksi pengguna.

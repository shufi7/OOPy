## Keputusan fondasi

- Warna brand tetap `#11999E`; action gelap dipakai untuk teks putih agar identitas dan aksesibilitas tidak saling mengorbankan.
- Action active lebih gelap untuk menandai penekanan tombol tanpa gerakan tambahan.
- Border pemisah `#D2EBE6` tetap ringan; border kontrol `#63827C` terpisah karena input perlu batas yang mudah dikenali.
- Teks utama `#40514E`, heading `#243B39`, dan muted `#526B66` menjelaskan peran informasi tanpa bergantung pada hitam untuk semua elemen.
- Alias `--oopy-primary`, `--oopy-blue`, `--oopy-sky`, `--oopy-bg`, dan lainnya tetap tersedia. `--oopy-on-primary` mempertahankan hitam pada bidang brand lama; action baru memakai `--oopy-on-action`. Ini mencegah komponen lama mendadak mendapat pasangan putih–brand yang kontrasnya rendah.
- Token canvas, heading, radius 8/14/20px, spacing 4/8/12/16/24/32/48px, font UI, dan monospace tersedia. Migrasi komponen di luar fondasi dilakukan pada tahap halaman masing-masing; kartu/hero tidak dirombak sekarang.
- Font Plus Jakarta Sans dan monospace kode dipertahankan karena sudah sesuai arah ruang belajar. Tidak ada font, logo, ilustrasi, gradien, glow, atau animasi dekoratif baru.

Viewport: **360, 390, 768, 1024, 1440px**. Browser: Edge headless 155. Semua kontrol yang disertakan dalam pemeriksaan hit area: tombol brand, hamburger, Run/Reset/Submit/Stop, tab, file explorer, hapus output, runtime retry, toggle password, kontrol evaluasi, dan tautan TOC. Radio button dioperasikan melalui label/area opsi; ukuran glyph radio tidak dipaksa menjadi 44px.

Pengujian menggunakan server dan SQLite sementara yang terpisah, dengan konten dari seeder proyek. Database asli tidak disentuh. Tes PHP menggunakan database in-memory. Grader pada server browser sengaja tidak tersedia untuk memeriksa failure state; respons sukses tertunda pada tes coding adalah simulasi kontrak UI, bukan bukti grading produksi.

CDN browser lingkungan ini diblokir. Versi asli Bootstrap, font, ikon, Monaco, dan Pyodide dipenuhi dari cache sementara audit lewat route Playwright; tidak ada dependensi atau loader aplikasi yang diganti. Tes lama dijalankan dengan preload cache sementara. `foundation.mjs` menerima cache opsional lewat `OOPY_ASSET_MANIFEST` dan URL server melalui `OOPY_BASE_URL`.

Saat penyusunan tes baru, penanganan fokus Monaco, token yang sedang dirender ulang, dan dialog beforeunload disesuaikan pada harness. Kegagalan awal harness tidak diatasi dengan mengubah perilaku aplikasi. Hasil akhir tersimpan sebagai PASS; source aplikasi tidak diedit lagi setelah verifikasi akhir interaksi.

Untuk menjalankan tes baru, gunakan database/server pengujian yang dapat dibuang, lalu tetapkan `OOPY_BASE_URL` dan, bila perlu, `OOPY_ASSET_MANIFEST` serta `OOPY_SCREENSHOT_DIR`. Mode `--interactions-only` mengulang pemeriksaan interaksi dengan mempertahankan hasil layout awal dalam direktori bukti yang sama; bukan pengganti pengujian layout setelah CSS berubah.
